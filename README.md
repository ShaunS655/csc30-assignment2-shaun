The front page of the website. It provides context to the subject and then my example list.

It details the source of the information and about why I chose this topic in particular. I like Clodsire so the image is Clodsire.

DETAILS PAGE:
This is the details of one specific character. I chose Clodsire as the example character.

NEW-CHARACTER-FORM:
This is the layout for adding a new character to the gallery.

STYLE.CSS
This is for the setting and layout of the area.
